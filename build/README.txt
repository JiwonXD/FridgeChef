냉털 셰프
=========================================

[게임 소개]
냉장고를 열면 랜덤 재료 18개와 오늘의 주제가 나옵니다.
먼저 재료를 골라 요리를 구상하고, 고른 재료만으로 요리합니다.
  재료 73종 (고기, 해산물, 달걀과 유제품, 채소, 과일, 밥과 면, 간식)
  즉석밥은 항상 냉장고에 들어 있습니다
  양념 16종, 주제 12가지
게임 시간 30분 안에 손질하고 조리한 구성 요소를 접시에 조립해 요리를 완성하세요.
공공 레시피 자료에서 뽑은 구성 요소 135개와 조립 규칙으로 요리 이름이 정해집니다.
AI 심사위원이 완성도를 100점 만점으로 채점합니다.

  주제 적합      30점
  재료 궁합      15점
  손질           15점
  조리법과 불    15점
  익힘과 온도    25점
  + 남은 시간 보너스 (최대 5점)
  - 남긴 재료 (골라 놓고 안 쓴 재료 1개당 4점)
접시마다 채점하고 재료 수로 가중 평균해 한 판 점수를 냅니다.

결과 화면에서 어디서 점수가 깎였는지 항목별로 보여 줍니다.
한 판 플레이 시간: 약 3~5분

[시간 규칙]
현실 시간은 흐르지 않습니다. 행동할 때만 게임 시계가 흘러갑니다.
  손질 (씻기, 껍질, 썰기 등)   정해진 시간 소모, 그동안 다른 행동 불가
  조리 기구에 넣기             불 세기와 시간을 정해 두면 자동 진행
                               진행 중에 다른 재료 손질 가능
  기다리기 버튼                0:30 / 1:00 / 다음 완료까지
물 끓이기, 기름 예열, 오븐 예열 시간도 실제처럼 걸립니다.

[실행 방법]
1. ZIP 파일 압축 풀기
2. FridgeChef 폴더의 FridgeChef.exe 더블클릭
   (설치 필요 없음, 인터넷 연결 필요 없음, Windows 10/11 64비트)
3. "Windows의 PC 보호" 창이 뜨면 [추가 정보], [실행] 순서로 클릭
   (서명하지 않은 개인 제작 프로그램이라 처음 한 번 뜰 수 있습니다)
4. F11 키로 전체 화면 전환

[조작 방법]
마우스로 플레이합니다.
  1. 재료 고르기 화면: 주제를 보고 쓸 재료를 클릭 (개수 제한 없음)
       골라 놓고 접시에 올리지 않은 재료는 1개당 4점 감점
       [요리 시작]을 누르면 고른 재료만 조리대에 올라갑니다
       요리 중에는 재료를 더 가져올 수 없습니다
  주방은 위에서 내려다본 ㄷ자 모양입니다.
    왼쪽: 가스레인지(화구 4개), 냉동실, 재움 볼
    위쪽: 싱크대, 조립용 쟁반, 도마, 재료 놓는 조리대
    오른쪽: 오븐, 전자레인지, 블렌더
    가운데: 타이머, 기다리기, 제출, 작업 창
  조리대 뒷줄은 날재료, 앞줄은 손질한 재료(유리 볼)와 익힌 재료(접시)입니다.
  2. 손질: 조리대의 재료나 도마를 클릭하면 재료가 도마에 올라가고 작업 창이 열림
       껍질 벗기기, 반 가르기, 깍둑, 한입, 얇게, 채, 다지기,
       달걀 풀기, 튀김옷, 으깨기, 밑간(양념 최대 3개), 버리기
     씻기: 싱크대 클릭, 씻을 재료 선택, 씻기
  3. 조리: 기구 클릭 후 작업 창에서 한 번에 설정
       화구: 도구(프라이팬, 웍, 냄비, 튀김 냄비, 찜기)
             준비(그대로, 기름 두르기, 기름 채우기, 물 채우기)
             조리법(굽기, 볶기, 튀기기, 끓이기, 찌기)
       불 세기(온도)와 시간, 넣을 재료 선택 후 [넣기]
       재료 없이 [예열]만 해 둘 수도 있습니다 (물 끓이기, 기름 달구기)
       조리 중인 기구를 누르면 재료 추가, 꺼내기
       조리 중인 모습이 기구 위에 그대로 보입니다
  4. 조리가 끝나면 재료가 조리대 앞줄로 돌아옵니다
       같은 기구에서 함께 조리한 재료는 한 그릇(구성 요소)이 되어 함께 움직입니다
       재료 아래 막대 색: 생 / 덜 익음 / 잘 익음 / 많이 익음 / 탐
  5. 쟁반에서 접시에 조립: 쟁반을 눌러 새 접시, 또는 재료 창의 + 버튼 (0:10)
       접시 이름이 조립에 따라 바뀝니다. 갈비찜 + 밥 = 갈비찜 정식
       접시를 누르면 구성 요소 빼기, 더 담기, 패스에 올리기
       접시를 여러 개 만들어 메인과 곁들임처럼 따로 낼 수 있습니다
  6. 타이머 옆 스테인리스 선반이 패스입니다
       완성한 접시를 패스에 올리고 종을 치면 심사를 받습니다 (1:00)

  책 아이콘   레시피 노트 (재료별 적정 조리 시간, 시간 소모 없음)
  재료와 아이콘에 마우스를 올리면 이름이 나옵니다.

  메뉴 (Esc 또는 메뉴 버튼)
    계속하기, 효과음 켜기/끄기, 배경음악 켜기/끄기, 전체 화면, 처음 화면, 게임 종료

  키보드
    Enter   시작 / 요리 시작 / 결과에서 랭킹 보기 / 다시 하기
    Esc     작업 창 닫기 / 메뉴 열고 닫기
    F11     전체 화면

[랭킹 확인 방법]
  처음 화면 오른쪽: TOP 10
  게임이 끝나면: 내 순위와 TOP 10 (내 기록 강조)
  기록은 PC에 파일로 저장되어 게임을 끄거나 PC를 껐다 켜도 유지됩니다.
    저장 위치: %APPDATA%\FridgeChef\ranking.json
    (게임 폴더를 옮기거나 다시 풀어도 같은 PC면 랭킹이 이어집니다)

  운영자용: 처음 화면에서 F8, 랭킹 전체 삭제

[참고]
  결과 화면은 60초 뒤 자동으로 처음 화면으로 돌아갑니다.
